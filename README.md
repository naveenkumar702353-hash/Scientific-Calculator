# Scientific Calculator 🧮

A scientific calculator built using **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript functions, DOM manipulation, event handling, mathematical operations, and building an interactive web application.

## 🚀 Features

* Basic arithmetic operations

  * Addition
  * Subtraction
  * Multiplication
  * Division
* Parentheses
* Decimal calculations
* Backspace
* Clear (`AC`)
* Square (`x²`)
* Cube (`x³`)
* Power (`xʸ`)
* Square root
* Y-th root
* Factorial
* Logarithm (`log`)
* Natural logarithm (`ln`)
* Trigonometric functions

  * `sin`
  * `cos`
  * `tan`
* Hyperbolic functions

  * `sinh`
  * `cosh`
  * `tanh`
* Exponential function (`eˣ`)
* `10ˣ`
* Pi (`π`)
* Random number generation
* Percentage
* Positive/negative toggle (`+/−`)
* Memory functions

  * `MC`
  * `M+`
  * `M−`
  * `MR`
* Degree/Radian mode

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout
* **JavaScript** – Calculator logic and user interaction

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use **VS Code with Live Server** to run the project.
